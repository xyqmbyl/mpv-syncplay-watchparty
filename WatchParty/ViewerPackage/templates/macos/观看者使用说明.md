# MPV Syncplay 观看者包（macOS）

这个包用于在 Mac 上加入房主的同步观影房间。你不需要下载房主的视频，
也不需要 AList 账号。视频通过 Tailscale 加密网络从房主电脑直接载入，
播放进度由 Syncplay 同步。支持 Apple Silicon（M1/M2/M3/M4）与 Intel
芯片的 Mac。

本包使用 Tailscale Device Sharing 后直连房主的
`http://100.x.x.x:5244`。不需要 Tailscale Serve，必须保持 Funnel 关闭。

## 第一次使用

1. 完整解压 ZIP（建议放在"下载"以外的位置，例如 `文稿/WatchParty`）。
2. 去除 macOS 隔离标记（本包未做付费公证，此步骤必需）。打开"终端"，
   执行：

   ```bash
   xattr -cr 把这里替换成解压出来的文件夹路径
   ```

   也可以把文件夹直接拖进终端窗口获得路径。
3. 请房主先在 Tailscale 后台把他的设备共享给你的 Tailscale 账号；打开
   房主发来的邀请并接受共享。
4. 双击 `观看者首次设置.command`。若提示无法打开（未公证），改用右键 →
   "打开"再确认一次即可。
5. 按安装界面完成 Tailscale 安装，使用你自己的账号登录；不要使用房主的
   账号，也不要索要房主密码。首次安装需要允许"系统扩展/后台服务"。
6. 等 Tailscale 菜单栏图标显示已连接，回到终端继续。确认地址与房主发来的
   完整 `http://100.x.x.x:5244` 一致；不一致时输入正确地址。
7. 程序会清除本地媒体发布映射，从观看者视角诊断房主地址，并在通过后打开
   mpv。诊断失败时先解决连接问题，不要选择"仍要继续"。

此包预设的房主媒体地址是：

```text
__ALIST_ORIGIN__
```

这个地址不是登录凭据。没有获得房主的 Tailscale 设备共享授权时，地址本身
无法访问视频。

## 每次观看

1. 双击 `启动观看.command`。
2. 在 mpv 中按 `Ctrl+Shift+S` 打开 Syncplay 面板。
3. 在左侧依次设置服务器、房间和昵称。服务器与房间必须和房主完全一致。
4. 进入"播放控制"，选择"加入 / 连接房间"。
5. 等房主从他的媒体目录打开视频。不要在本机选择视频；mpv 会自动载入远程
   视频，并在加载完成后进入 READY。

如果房主使用默认服务器，服务器是 `syncplay.pl:8995`。房间名应由房主另行
告知，建议使用不容易猜到的房间名。

## 弹幕（不影响同步，和房主互不干扰）

mpv 下方的控制栏里有 `弹幕开关`、`搜索弹幕`、`从源添加弹幕`、`弹幕设置`；
也可以按 `j` 开关弹幕，按 `Ctrl+d` 搜索弹幕。

- 弹幕只在你自己的电脑上显示，不会发送给房主或其他观看者。
- 弹幕跟着本机播放进度走：视频暂停时弹幕停住，继续播放或跳转后会立刻对上
  房主的进度。

## 排查

- 面板打不开：使用 `Ctrl+Shift+S`。
- 双击 .command 提示"无法打开，因为无法验证开发者"：先执行上面的
  `xattr -cr` 步骤；或右键 → 打开。
- 显示 Tailscale 未连接：打开 Tailscale 菜单栏图标并重新登录。
- 能进房间但视频不加载：确认你已接受房主的设备共享邀请，并让房主保持
  Tailscale、AList 和 mpv 运行。
- 房主更换地址：在终端中运行
  `python/bin/python3 portable_config/syncplay/tailscale_integration.py configure-viewer`
  并按提示输入房主的完整 `http://100.x.x.x:5244` 地址。
- Tailscale 已连接但诊断不通：核对房主当前 `100.x` 地址。不要让房主开启
  Funnel。

观看结束后可以关闭 mpv。Tailscale 保持登录即可，无需每次重装。
