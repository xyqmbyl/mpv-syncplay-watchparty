# WatchParty 使用说明（macOS，房主 / 观看者共用）

同一个安装包既是房主包，也是观看者包。角色不在下载时决定，而是在 mpv 面板里
选择：按 `Ctrl+Shift+S` 打开面板 → 「联机」→「运行模式」→ 选「房主模式」或
「观看者模式」。随包 AList 只在房主模式下启动，观看者模式不会占用本机任何
端口。支持 Apple Silicon（M1/M2/M3/M4）与 Intel 芯片的 Mac。

安全边界：媒体只经 Tailscale 加密网络（tailnet）访问，不启用 Tailscale
Funnel，不把 AList 暴露到公网；管理密码只保存在本机，绝不写进包里。

## 直接打开播放器

双击 `mpv.app` 即可加载随包的自定义 UI 和中文字体，也支持把视频拖到应用图标。
请把整个解压文件夹一起移动，保留 `mpv.app` 与 `portable_config` 的相对位置。
联机观看仍按下文完成首次设置，再用 `启动.command` 启动。

## 第一次使用

1. 完整解压 ZIP（建议放在"文稿"里）。
2. 去除 macOS 隔离标记（本包未做付费公证，此步骤必需）。打开"终端"执行：

   ```bash
   xattr -cr 把这里替换成解压出来的文件夹路径
   ```

   也可以把文件夹拖进终端窗口获得路径。macOS 15 及以上若提示"无法验证
   开发者"，还可打开 系统设置 → 隐私与安全性，找到被拦的 WatchParty
   文件点"仍要打开"。包内启动脚本每次运行也会自动清除本包隔离标记。
3. 双击解压文件夹顶层的 `首次设置.command`（与 `WatchParty`、`mpv.app`
   平级，不在 WatchParty 子文件夹里）。它会检测 Tailscale，缺失时打开包内的
   官方安装包（哈希已校验），并完成两项准备：装好后把 Tailscale 拖入
   "应用程序"、在系统设置里允许其系统扩展、登录你自己的账号。只想看本机影片
   的话，这一步可以跳过。
4. 双击 `启动.command` 打开 mpv，然后按 `Ctrl+Shift+S` 打开面板，进入
   「联机」→「运行模式」，选择房主模式或观看者模式。

## 房主模式

1. 选择房主模式后，向导会自动：启动随包 AList → 生成管理员密码（保存在
   `WatchParty/ADMIN_PASSWORD.txt`，请勿外传）→ 开启匿名只读与 HTTP Range →
   自检 → 写入房主配置。macOS 首次运行时若系统询问是否允许 AList 接收入站
   连接，选择"允许"。
2. 最后一步需要你在网页上手动完成：登录
   <https://login.tailscale.com/admin/machines>，找到本设备，点 Share，
   把共享链接发给观看者。
3. 把视频放进 `WatchParty/media`。外部路径必须已在面板里配置 `alist_map`
   映射，观看者才能自动加载。
4. 在面板里设置房间与昵称，选择"加入 / 连接房间"，再从 `WatchParty/media`
   打开视频。

## 观看者模式

1. 请房主先在 Tailscale 后台把他的设备共享给你的 Tailscale 账号，并接受邀请。
2. 在面板里进入「联机」→「运行模式」→「观看者模式」，按提示输入房主发来的
   完整地址 `http://100.x.x.x:5244`，然后确认。
3. 观看者模式会清除本机的媒体发布映射，并从观看者视角诊断房主地址；诊断失败
   时先解决连接问题，不要强行继续。
4. 在面板左侧依次设置服务器、房间和昵称（必须与房主完全一致；房主使用默认
   服务器时为 `syncplay.pl:8995`），进入"播放控制"选择"加入 / 连接房间"。
5. 等房主从他的媒体目录打开视频。不要在本机选择视频；mpv 会自动载入远程视频，
   并在加载完成后进入 READY。

房主地址不是登录凭据：没有获得房主的 Tailscale 设备共享授权时，地址本身无法
访问视频。房主更换地址后，可在面板里重新选择观看者模式并输入新地址。

## 切换角色

- 「运行模式」随时可以重选。改回「仅本机观看」会关闭随包 AList 与联机共享，
  只播放本地文件。
- 切换角色会重启本机的 Syncplay 客户端进程，切换完成后请在面板里重新选择
  "加入 / 连接房间"。

## 弹幕（不影响同步，和房主互不干扰）

mpv 下方的控制栏里有 `弹幕开关`、`搜索弹幕`、`从源添加弹幕`、`弹幕设置`；
也可以按 `j` 开关弹幕，按 `Ctrl+d` 搜索弹幕。弹幕只在本机显示，不会发送给
房主或其他观看者，并跟随本机播放进度。

## 排查

| 现象 | 处理 |
| --- | --- |
| 面板打不开 | 使用 `Ctrl+Shift+S`。 |
| 双击 .command 提示"无法验证开发者" | 执行 `xattr -cr 解压目录`，或在 系统设置 → 隐私与安全性 里点"仍要打开"。 |
| 提示 AList 未能启动 | 确认 `WatchParty/alist/alist` 存在；必要时双击 `首次设置.command` 重试。 |
| Tailscale 未连接 | 打开 Tailscale 菜单栏图标重新登录。 |
| 能进房间但视频不加载 | 确认已接受房主的设备共享邀请，且房主保持 Tailscale、AList 与 mpv 运行。 |
| Tailscale 已连接但诊断不通 | 核对房主当前的 `100.x` 地址；不要让房主开启 Funnel。 |
| 控制栏出现方块/问号而不是图标 | 确认 `portable_config/fonts` 里两个图标字体还在，再运行一次 `启动.command`（会复制一份到 `~/Library/Fonts` 兜底），然后重启 mpv。 |
| 按 `i` 的媒体信息里 MediaInfo 一栏为空 | 本包不携带 MediaInfo 可执行文件，`brew install mediainfo` 后才会显示，其余统计不受影响。 |

## macOS 专属说明

- 界面图标字体随包放在 `portable_config/fonts`，mpv 通过 `--sub-fonts-dir`
  （默认 `~~/fonts`）交给 libass，libass 用自带的 FreeType 内嵌字体通道解析，
  macOS 上同样生效。每次运行 `启动.command` 时脚本还会把
  `MaterialIconsRound-Regular.otf`、`uosc_textures.ttf` 复制一份到
  `~/Library/Fonts` 作为兜底（已存在则跳过，不需要时可自行删除）。
- 同一个脚本会在包内按需创建 `portable_config/_cache/{icc,shader,watch_later}`
  缓存目录（发布包不携带缓存），删除它们不影响使用，下次启动会自动重建。
- 房主地址变更后，也可以在终端运行
  `python/bin/python3 portable_config/syncplay/tailscale_integration.py configure-viewer`
  并按提示输入房主的完整 `http://100.x.x.x:5244` 地址。
- 房主侧诊断命令：
  `python/bin/python3 portable_config/syncplay/watchparty_setup.py doctor --role host`
