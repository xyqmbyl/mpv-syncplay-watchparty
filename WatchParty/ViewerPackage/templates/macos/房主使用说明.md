# WatchParty 房主包（macOS）

这个包把你的 Mac 变成同步观影的房主：随包 AList 负责把媒体目录通过
Tailscale 加密网络分享给观看者，Syncplay 负责所有人的播放进度同步。
支持 Apple Silicon（M1/M2/M3/M4）与 Intel 芯片的 Mac。

安全边界：媒体只经 tailnet 或局域网访问；不启用 Tailscale Funnel，
不把 AList 暴露到公网；管理密码只保存在本机，绝不写进包里。

## 直接打开播放器

双击 `mpv.app` 即可加载随包的自定义 UI 和中文字体，也支持把视频拖到应用图标。
请将整个解压文件夹一起移动，保留 `mpv.app` 与 `portable_config` 的相对位置。
联机观看仍按下文完成首次设置，然后使用 `启动.command` 启动所需服务。

## 第一次使用

1. 完整解压 ZIP（建议放在"文稿"里）。
2. 去除 macOS 隔离标记（本包未做付费公证，此步骤必需）。打开"终端"，执行：

   ```bash
   xattr -cr 把这里替换成解压出来的文件夹路径
   ```

   也可以直接把文件夹拖进终端窗口获得路径。macOS 15 及以上若提示"无法
   验证开发者"，还可以打开 系统设置 → 隐私与安全性，找到被拦的
   WatchParty 文件并点"仍要打开"。包内启动脚本每次运行时也会自动清除
   本包的隔离标记。
3. 双击解压文件夹顶层的 `首次设置.command`（与 `WatchParty`、`mpv.app`
   平级，不在 WatchParty 子文件夹里）。它会：
   - 启动随包 AList 并生成管理员密码（保存在 `WatchParty/ADMIN_PASSWORD.txt`，
     请勿外传）；
   - 自动开启匿名只读与 HTTP Range，并做与观看者一致的自检；
   - 检测 Tailscale：未安装时会打开包内的官方安装包，装好后把 Tailscale
     拖入"应用程序"并在系统设置里允许其系统扩展，登录你自己的账号；
   - 把观看者要用的 `http://100.x.x.x:5244` 写入配置。
4. 最后一步需要你在网页上手动完成：登录
   <https://login.tailscale.com/admin/machines>，找到本设备，点 Share，
   把共享链接发给观看者。
5. 把视频放进 `WatchParty/media`。

## 每次开播

1. 双击解压文件夹顶层的 `启动.command`（会自动确保 AList 在运行并打开 mpv）。
2. 在 mpv 中按 `Ctrl+Shift+S` 打开 Syncplay 面板，设置房间和昵称，
   选择"加入 / 连接房间"。
3. 从 `WatchParty/media` 打开视频。房主也可以播放本地任意文件，但外部
   路径必须已在面板里配置 alist_map 映射，观看者才能自动加载。

## 提示

- 房主侧诊断：终端运行
  `python/bin/python3 portable_config/syncplay/watchparty_setup.py doctor --role host`。
- macOS 防火墙若询问是否允许 AList 接收入站连接，选择"允许"。
- 观看者加入同一 Syncplay 服务器与房间后，会自动载入你正在播放的视频。
